# 拒绝大鱼大肉攻击，月子餐这样吃才科学

> 更新时间：2026-09-17 (UTC+8)

吃，一直是中华民族的头等大事

无论男女老少、无论天南海北

只要在中国

我们对于“吃”的态度

一定是一致的

而当生了孩子后坐月子时

对于吃什么，怎么吃

又上升到一个新的高度

这时吃的东西甚至有了专属词汇

**——月子餐**

对于刚生产完的宝妈来说，月子餐的确非常重要，吃好月子餐不仅关系着产后身体恢复，更关系着母乳喂养能否顺利，关系到宝宝的“饭碗”。

所以有“经验”的婆婆或者妈妈，就会给宝妈每天炖补品，什么花生猪脚汤、老母鸡汤、木瓜鲫鱼等轮番上阵，进行连绵不绝的油腻攻击。

但这些真的是宝妈需要的营养吗？宝妈吃不下，闻不了还要继续吃吗？

**如何使月子餐科学又营养？**

第一周：

代谢排毒

第一周排除恶露、利水消肿、化瘀生新，温经止痛为主，促进伤口愈合及恢复子宫机能。

第一周妈妈才刚生产完，处于排恶露，愈合伤口的时期。产后的头三天，月子餐不能吃油腻的食物，一定要以清淡的食物为主，这个时候新妈妈的乳腺管还没打开，如果吃的太补奶水有可能会堵在乳房中出不来，而且会出现奶涨的现象。

分娩中妈妈消耗了大量能量，身体处于极度虚弱的状态，所以这周饮食应该以高热量为主。

第二周：

修复组织

进入月子第二周，妈妈的伤口基本上愈合，这时期可以多吃些增强骨质和腰肾功能的食物，以防日后妈妈出现腰痛的情况。同时也可以开始吃催奶的汤，为宝宝的口粮做准备。

虽说叫“催奶汤”，很多产妇都只喝汤不吃肉，其实这样不够营养，因为汤里营养最多只有25%，其余都在肉里。所以，汤汁要喝，料更不能舍弃。而且油多的汤要少喝，妈妈们可以等汤凉下来后用勺子撇去浮油，加热再喝。

有热性的东西，如红枣、桂圆、火腿、老母鸡等等，都要在恶露干净后再加入月子餐食谱中去，否则恶露会一直不干净的。

第三周：

滋补元气

第三周，以滋养泌乳、补中益气，以滋阴养血、调补冲任为主，增强免疫力。

经过前两周的精心调养，妈妈身体各种功能都已逐步恢复，母乳质量也趋于稳定，产后第三阶段，也就是第三周的调补重点就在于滋养泌乳，补充元气。

因为母乳是妈妈的精血生成的，只要产后调补得宜，气血顺畅，奶水就会源源不绝，而哺乳会消耗大量能量，所以这时滋养进补是最恰当的时机。

第四周：

补充体力

第四周，以滋肾益精，安神健脑，养肝补血为主，清除邪气，预防机体老化。此时身体逐渐复原，但需注意饮食上要营养均衡，不要补过头了。对于鱼、肉、蛋、奶、豆制品的摄入都要适量，偶尔可以吃点粗粮，并保证水果和蔬菜的摄入，少摄入油脂类。

由于产妇雌激素水平较低，可能会有脸上会出现斑点、头发脱落等状况，那就应该多摄取维生素（A、B、C）、碘、钙等矿物质。平时饮食中，还应多吃山药、苡仁等滋阴食品。

另外，有的产妇由于奶水不多，宝宝不够吃，那么就要多喝鲫鱼汤、鸡汤等，有助于补充水分。

第五周：

养颜美容

月子5周，产妇基本可以恢复孕前的生活。但在饮食上注意不要进食生冷刺激类的食物，以免影响乳汁分泌和身体康复。并可采用食补和按摩的方式淡化妊娠纹。

这个时期是是妈妈即将迈向正常生活的过渡期，更应该严格按照坐月子的饮食和休养方式，使气血更加充足，才能改善体质，巩固整个坐月子的成果，帮助妈妈达到最佳体力与健康状态。

第六周：

固肾培元

以补益肝脾肾为主，固肾培元。

产后和宝宝一起去做产后42天检查，这时基本已恢复正常身体了，产妇也应恢复正常的饮食了。有的产妇开始考虑减肥，这主要从饮食上着手，但是不应刻意控制饮食，可适当做些运动，锻炼身体。

月子期除了这些应该吃的，还有一些不该吃的(对整个哺乳期都适用哦)

1. 忌辛辣温燥食物，韭菜、蒜薹、辣椒、茴香、酒等食物与饮品，过食会导致产妇口舌生疮、便秘或痔疮发作。

2. 忌硬、咸、寒凉生冷的食物，如西瓜、梨、葡萄少吃。别的常温水果如香蕉、橘子、苹果可以吃。泡菜、腌菜不要吃。

3. 忌麦乳精、巧克力、麦芽、大麦茶，麦芽是回奶的主药，含麦芽的食物都不建议吃。燕麦片少吃，有的宝妈因体质原因吃后也会少乳。

4. 忌刺激性食物，浓茶、咖啡、酒精、蜂蜜、高糖食物，这些会影响产妇的睡眠及肠胃功能，也可通过乳汁进入宝宝体内，影响宝宝发育，建议不要食用。
