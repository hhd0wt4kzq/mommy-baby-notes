# 试管婴儿成傻子状告医院_医生试管婴儿受害人上千人！

> 更新时间：2026-09-16 (UTC+8)

试管婴儿为许多不孕不育家庭带来了希望。然而近年来随着试管婴儿技术的广泛应用，也出现了不少争议和纠纷。其中关于试管婴儿智力缺陷的诉讼尤为引人注目。

2025年轰动全国的试管婴儿成傻子状告医院案，将试管婴儿技术的安全性问题再次推上了风口浪尖。

试管婴儿智力缺陷质疑

原告王女士夫妇，通过山东省立医院生殖医学中心进行试管婴儿技术，于2018年生下一名女婴。然而夫妻二人发现，孩子出生后发育迟缓，智力明显落后于同龄儿童。经多家医院检查确诊为脑瘫，伴有严重智力障碍。

王女士夫妇认为，孩子的智力缺陷与试管婴儿技术有关，遂将山东省立医院生殖医学中心告上法庭，要求赔偿巨额经济损失和精神损害抚慰金。

医院否认责任

山东省立医院生殖医学中心坚称，试管婴儿孩子的智力缺陷与试管婴儿技术无关。医院提供了大量医学证据，证明试管婴儿技术不会对胎儿的智力发育造成影响。

司法鉴定之争

法院委托山东省司法鉴定中心对孩子的智力缺陷原因进行鉴定。鉴定中心出具的鉴定报告认为，孩子的智力缺陷与试管婴儿技术之间存在关联性但无法确定因果关系。

庭审焦点

庭审中，双方围绕以下焦点展开激烈辩论：

试管婴儿技术是否会导致胎儿的智力缺陷？

医院在试管婴儿技术实施过程中是否存在过错？

王女士夫妇主张的赔偿金额是否合理？

一审判决

2025年6月，济南市中级人民法院对本案进行了一审宣判。法院认定，山东省立医院生殖医学中心在试管婴儿技术实施过程中存在过错但孩子的智力缺陷与试管婴儿技术之间的因果关系尚不明确。因此法院判决医院承担部分赔偿责任，赔偿王女士夫妇医疗费、误工费等损失共计人民币30万元。
