# 给宝宝添加辅食要注意什么 什么情况下不能给宝宝添加辅食

> 更新时间：2026-09-19 (UTC+8)

给宝宝添加辅食时，这七个原则要牢记，不然会伤害孩子胃肠

原则一：不要操之过急

前段时间，山东潍坊市益都中心医院接诊了一个5个月的孩子，孩子到了医院已经出现寒战，哭闹加剧，足部发白等症状。

医接到孩子发现是严重的过敏反应，血管神经性水肿，病情非常的危重，而在抢救过程发现孩子哭闹停止，面色口唇青紫，喉头水肿。

医赶紧抱着孩子跑到中心输液室进行输液，幸好孩子被抢救过来！

后来孩子的妈妈说是给5个月的孩子添加了半个鸡蛋黄，没多久孩子就出现了过敏的反应！

所以家长给孩子添加辅食一定不要操之过急，建议孩子6个月再添加辅食，就是为了预防这样的情况。

而给孩子吃一种新的食物，一定要少量的尝试，比如说给孩子吃鸡蛋的蛋黄，建议是从1/8或者1/4开始添加，不要一开始就给孩子吃一个或者半个。

原则二：不要盲目地添加

比如说鸡蛋的蛋白至少要等孩子10个月再慢慢地添加。

而一些相对容易过敏的鱼虾类，给孩子添加的时候也要少量添加，添加一次之后观察2~3天，发现孩子没有过敏，再慢慢的给孩子加量。

千万不要觉得给孩子吃一次没有问题，就大量地给孩子吃，万一孩子出现过敏就很麻烦。

原则三：不要跟其他同龄孩子对比

每个孩子的长发育都不太一样，有一些孩子可能长得快，在8个月他已经可以吃一碗稀饭了。

但是你们家孩子可能8个月只能吃小半碗，不要觉得别人家的孩子能吃这么多，我们家的孩子也要吃这么多。

每个孩子的胃肠消化能力，以及长发育情况都不太一样，千万不要拿孩子来做比较。

原则四：不要给孩子的辅食加除了油之外的调料品

比如说盐，糖，味精，鸡精，酱油等这些调节食物的调料品，不要出现在孩子的辅食中，孩子在一岁之前不需要加盐。

而孩子在一岁之前，如果给孩子吃的食物是素食，可以适当地加一些植物油，比如说亚麻籽油，橄榄油，这些都是可以的，但是不要加其他的调味品。

因为孩子的肾脏排泄能力弱，给孩子加调料品反而会伤害孩子的身体。

原则五：不要在孩子病的时候添加辅食

孩子在病的时候，胃肠的消化能力会更弱，所以虽然孩子6个月了，但是他这段时间感冒病，或者是长幼儿急疹，就不要着急的给孩子添加辅食。

一定要等到孩子病彻底好了，精神食欲各方面没有问题，再给孩子添加辅食。

原则六：不要在孩子更换奶粉的时候添加辅食

有些喝奶粉的孩子会在7个月换奶粉，从一段换到二段，如果给孩子换奶粉，那么这个期间不要给孩子添加新的辅食，可以先换完奶粉，孩子没有问题了再添加辅食。

或者给孩子添加了一种辅食，再给孩子换奶粉。

总之更换奶粉和添加新的辅食不能同时进行，因为万一过敏不知道是哪一种引起的。

原则七：不要在孩子打预防针的时候添加辅食

6个月的时候孩子需要打乙肝疫苗，而孩子在接种疫苗前后几天不要添加辅食。

如果打疫苗之前给孩子添加辅食，万一孩子出现不适的症状，就会影响孩子接种疫苗。

孩子在打疫苗之后的一个星期左右，也会出现身体不适的症状，这时候添加辅食也容易出现过敏的情况。
